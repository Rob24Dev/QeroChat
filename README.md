<h1 align="center">QeroChat 💻</h1>
<h3 align="center">This is one of my most recent projects, which I’ve been working on for quite some time. It’s the backend for a chat app I’m developing to improve my Spring Boot skills. I wrote all the backend code myself, while the frontend is currently generated using AI.</h3>
<h4>What can it do?</h4>

- Register, log in, and reset a user's password <br>
- Entire messaging system, including creating multiple chats with a single user <br>
- Friends system and customizable user profile  <br>
- Automated email notifications (verifications, password resets, waitlist confirmations) <br>
- Beta waitlist signup with newsletter options <br>
- Upload files such as profile pictures
