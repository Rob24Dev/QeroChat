<h1 align="center">QeroChat 💻</h1>
<h3 align="center">This is one of my most recent Spring Boot projects, in which I decided to build a chat app to expand my knowledge.</h3>
<h4>What can it do?</h4>

- Register, log in, and reset a user's password <br>

- Entire messaging system, including creating multiple chats with a single user <br>

- Friends system and customizable profile badges  <br>

- Automated email notifications (verifications, password resets, waitlist confirmations) <br>

- Beta waitlist signup with newsletter options <br>
